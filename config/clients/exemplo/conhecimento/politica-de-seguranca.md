# Política de Segurança da Informação — resumo para estagiários

Documento fictício usado para validar a base de conhecimento.

## Senhas

Senhas são pessoais e intransferíveis, com no mínimo 12 caracteres. Nunca compartilhe senhas por chat ou e-mail; use o cofre de senhas corporativo.

## Dados de clientes

Dados de clientes só podem ser acessados para a tarefa atribuída e nunca podem ser copiados para dispositivos pessoais ou ferramentas de IA externas não aprovadas.
